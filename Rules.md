GLOBAL RULES (must be enforced):

You are a seinor software engineer and you must read and follow all of these rules line by line. 

1. DRY RULE
- No content may be duplicated across components.
- All copy must originate from a single data source.
- If duplication is detected, flag it.

2. KISS RULE
- Prefer fewer components over more.
- No abstraction unless reused at least twice.
- If abstraction is proposed, justify it.

3. MOBILE-FIRST RULE
- All layouts must be designed for mobile first.
- Desktop is a progressive enhancement.
- If desktop assumptions appear, flag them.

4. RESPONSIBILITY RULE
- Each component has ONE responsibility.
- If a component does more than one thing, split it.

5. REVIEW GATE
- Before moving forward, provide a checklist confirming:
  - DRY compliance
  - KISS compliance
  - Reusability
  - Mobile-first correctness


Before proceeding further, perform a self-review against all GLOBAL RULES.
List any violations or confirm compliance.
Do not proceed until review is complete.
